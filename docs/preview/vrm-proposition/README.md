# Proposition d’interface VRM
Maquette HTML responsive autonome, sans connexion aux API ni modification de l’app en production. Les données et illustrations sont fictives. Annonces et ventes sont les deux sections présentées ; achats/messages et les actions ouvrent seulement une indication de démonstration.

Ouvrir index.html ou servir le dossier via un serveur HTTP. Recherche, filtre taille, tri par prix, réinitialisation et menus sont interactifs. Contrôles Chromium effectués à 390 et 1440 px : filtrage, passage ventes, dialogue de simulation, absence d’erreurs JS et de débordement horizontal. Captures annonces/ventes disponibles pour ces deux largeurs.

Les actifs de marque de l’app n’ont pas été modifiés. Vinted est identifié ici par son nom et une icône de sac pour ne pas proposer un nouveau logo.

Révision mobile : boutons dessinés sur 28–32 px avec zone de clic élargie ; actions Modifier/Expédier alignées à droite dans chaque ligne, comme sur ordinateur. Captures régénérées après validation.

Révision allongée : marges latérales réduites, photos portrait de 54 × 104 px et textes légèrement plus lisibles sur téléphone. Boutons compacts conservés à droite.

Révision actions : groupe horizontal Modifier/Expédier et menu côte à côte à droite de chaque paire, centré verticalement. Aucun empilement de boutons sur mobile.

Vue mobile compacte : résumé financier en bande unique, en-tête et espacements réduits, lignes de 100 px environ. Aucun zoom forcé ni réduction de l’échelle du navigateur. Boutons horizontaux conservés.

Finition des commandes : icônes SVG homogènes, libellés et icônes alignés sur une ligne, menu secondaire discret et sélection de navigation soulignée. Logos de production inchangés.

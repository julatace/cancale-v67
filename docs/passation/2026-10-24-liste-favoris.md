# Liste compacte des favoris reçus — 24 octobre 2026

Julien demande une petite liste avec photo de notification, nom si disponible et cases de sélection pour préparer les messages. La liste est ajoutée dans Vinted → Messages → Favoris reçus, chargée uniquement au clic et pour un compte précis. Le choix explicite du compte prime sur le compte actif détecté ; choix « Tous » sans compte actif confirmé = choix demandé, aucune lecture mélangée.

Source : vraie forme confirmée par le diagnostic utilisateur (notifications[], id string, body, link, user_id, updated_at, pagination). Les formulations d’ajout en favori reconnues sont affichées ; une offre ou une vente ne devient pas un favori sur le seul mot « favoris ». Déduplication par identifiant de notification uniquement. Le texte reçu est conservé et décodé ; user_id n’est jamais interprété comme l’identifiant du destinataire. Un nom séparé vient d’un acteur explicitement fourni ; sinon le nom peut rester dans le texte natif. Photo : URL image Vinted présente dans la notification, pas une photo inventée ou prise d’une autre annonce. Repli si image absente/inaccessible. Liens web Vinted HTTPS seulement, sans reconstruction d’une destination à partir d’un pseudo ou d’un titre ; le pays du compte est conservé pour les liens relatifs.

Liste bornée, 50 lignes affichées puis « suivants », hauteur compacte et bouton Masquer pour retrouver les conversations. Sélection individuelle ou dix premiers, dix par préparation, effacée à l’actualisation/changement de compte/session. Champ de message, copie explicite et liens Vinted par notification. Le texte de remise n’est pas présenté comme une offre formellement créée.

**Pas d’envoi direct ni automatique activé.** Le plafond de dix est un plafond de préparation, pas encore un quota d’envoi atomique par heure. L’historique complet reste non vérifié : le capteur 5.214 conserve la capture reçue, il n’y a pas ici d’archive cumulative de toutes les anciennes notifications ni de pagination active nouvelle. La couverture reçue et le nombre de pages indiqué par Vinted sont affichés, sans promettre tous les favoris.

Diagnostic v3 conservé en accordéon : formes de liens et noms de paramètres connus seulement, valeurs/identifiants/pseudos masqués ; mention de favori = indice textuel, pas preuve de destinataire. Cela doit permettre de vérifier le raccordement avant l’envoi futur. Pas de nouvelle extension à installer pour cette interface.

Validation : 20 tests unitaires favoris/diagnostic, 51 contrôles React de la liste et 30 du diagnostic à 320/390/1512 px, 42 achats/messages dans l’app complète dont lecture d’une capture du compte choisi, sélection et masquage. Build réussi et captures inspectées. Essais sur données simulées uniquement, aucune action Vinted ni écriture de production. Premier banc intégré sans compte choisi avait logiquement trouvé le bouton désactivé : parcours corrigé pour choisir explicitement le compte, puis retour à Tous pour les vérifications de messagerie.

# 11 nov. 2026 — vert-11nov : tous les audits et les bancs principaux au vert

Branche `claude/vert-11nov`, partie de `origin/claude/integration-11nov-e4` (= main + paquet E4).
Contexte : 5 paquets mis en ligne alors que les contrôles GitHub n'avaient pas tourné (installation
du navigateur ratée chez GitHub). Julien : « corrige tout et mets en ligne quand c'est vérifié ».

Règle suivie : vrai défaut ⇒ l'app est corrigée ; contrôle périmé par une décision récente ⇒ porté
sur la règle actuelle, prouvé par mutation (la règle réaffaiblie ⇒ rouge) ; aucun garde-fou relâché,
aucune exception ajoutée (`scripts/audits-exceptions.json` reste vide).

Outil neuf : `scripts/_tr-fr.cjs` — depuis la traduction, un libellé d'écran s'écrit `tr('clé')` ;
un audit qui jugeait un texte le juge dans le français (`src/i18n/langues/fr.js`, la source), par la
clé posée. Une clé absente reste `tr('…')` : l'audit rougit (rien n'est deviné).

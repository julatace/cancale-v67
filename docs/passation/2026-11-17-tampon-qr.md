## La règle (App.jsx, « LA MENTION VRAIMENT JUSTE AU-DESSUS DU CODE », `placerMentionSurCode`)

- **Le code visé** : le plus grand code 2D (QR, DataMatrix, MaxiCode) de l'étiquette (dans son cadre s'il est connu) ;
  un code 2D de côté < 12 % du petit côté de l'étiquette est décoratif ; **sans code 2D, le code-barres principal**
  (le plus grand) ; sans aucun code, la règle d'avant (centrée sous l'adresse).
- Les morceaux d'un code sont **réunis** (`boiteEntiereCode` : l'encre reliée, blancs < 1,6 mm × 0,8 mm franchis,
  jamais la zone de silence) ; les codes 2D épars que la carte des codes ne voit pas (MaxiCode) sont cherchés à part
  (`codes2DEpars`, même tri `estUnCode`).
- **Le sens de l'étiquette** : celui de ses lignes de texte autour du code (`rendu.textes`, lu par pdf.js dans
  `rendrePremierePage`) ; une étiquette passée au noir pur (une image) reprend les lignes de la page vectorielle
  (`th.textes`) ; sans texte, le quart de tour que VRM lui a donné sur le rouleau (`th.sens`). La mention s'écrit
  dans ce sens, au-dessus du code **dans le repère de l'étiquette**.
- **Centrée** sur l'axe du code ; le bas des lettres (jambage du « p ») à **3 mm** du code (essais 3 · 3,5 · 2,5 · 4 ·
  2,25 mm) ; la bande est lue sur le rendu (lettres + 0,5 mm : aucune encre, aucune zone interdite, dans le cadre de
  l'étiquette et hors de la marge non imprimable) ; sinon la police **rapetisse** d'un demi-point jusqu'à 4,5 pt ;
  sinon **aucune mention** (`via: 'aucune-place'`) — jamais dessous, jamais à côté.
- Inchangé : les places choisies par Julien dans Paramètres (bas, coins, posée à la main) ; le cartouche N°.

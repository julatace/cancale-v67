## La règle (App.jsx, « LA MENTION VRAIMENT JUSTE AU-DESSUS DU CODE », `placerMentionSurCode`)

- **Le code visé** : le plus grand code 2D (QR, DataMatrix, MaxiCode) de l'étiquette (dans son cadre s'il est connu) ;
  un code 2D de côté < 12 % du petit côté de l'étiquette est décoratif ; **sans code 2D, le code-barres principal**
  (le plus grand) ; sans aucun code, la règle d'avant (centrée sous l'adresse).
- Les morceaux d'un code sont **réunis** (`boiteEntiereCode` : l'encre reliée, blancs < 1,6 mm × 0,8 mm franchis,
  jamais la zone de silence) ; les codes 2D épars que la carte des codes ne voit pas (MaxiCode) sont cherchés à part
  (`codes2DEpars`, même tri `estUnCode`).
- **Le sens de l'étiquette** : celui de ses lignes de texte autour du code (`rendu.textes`, lu par pdf.js dans
  `rendrePremierePage`) ; une étiquette passée au noir pur (une image) reprend les lignes de la page vectorielle
  (`th.textes`) ; sans texte, le quart de tour que VRM lui a donné sur le rouleau (`th.sens`). La mention s'écrit
  dans ce sens, au-dessus du code **dans le repère de l'étiquette**.
- **Centrée** sur l'axe du code ; le bas des lettres (jambage du « p ») à **3 mm** du code (essais 3 · 3,5 · 2,5 · 4 ·
  2,25 mm) ; la bande est lue sur le rendu (lettres + 0,5 mm : aucune encre, aucune zone interdite, dans le cadre de
  l'étiquette et hors de la marge non imprimable) ; sinon la police **rapetisse** d'un demi-point jusqu'à 4,5 pt ;
  sinon **aucune mention** (`via: 'aucune-place'`) — jamais dessous, jamais à côté.
- Inchangé : les places choisies par Julien dans Paramètres (bas, coins, posée à la main) ; le cartouche N°.

## Second temps : la page « Tampons des bordereaux » et la mention qui ne s'enlève plus

Julien (capture de Paramètres → Imprimante) : « ce ne sont pas les vrais bordereaux des transporteurs, améliore le
visuel de cette page et ne donne pas la possibilité d'enlever créé par vrm ».

- **La mention ne s'enlève plus** (`src/impression/tampons.js`) : toute case `mention: false` rangée (pour tous, pour un
  type, l'ancien mode « rien ») est relue `true` ; `placeMention` toujours `qr`, taille M, aucune place à la main
  (`avecPlace(…, 'm', …)` n'écrit rien, `placesDeForme().m` vaut null). L'impression la pose toujours
  (`veutMention = true`, `k: 1, place: 'qr', libre: null` dans `tamponnerBordereau`). La liste courte « Rien » de
  Paramètres → Impression s'appelle « Sans N° (la mention reste) » (5 langues).
- **Aucun contrôle** : la case, la taille et la place de la mention sont retirées de la page ; dans la scène (feuille
  de Paramètres ET aperçu avant impression) la mention est montrée, **verrouillée** (`data-verrou`, aucun geste, aucun
  clavier) ; le bouton « Mention à sa place d'origine » de l'aperçu est retiré.
- **Ses vrais bordereaux** (`src/parametres/TamponsBordereaux.jsx`) : la liste de ses `email_bord_*` en scalaires
  (`meta->>transporteurPdf`, `transporteur`, `receivedAt`, `filename`, `pdfPurged` — jamais `select=data`), le plus
  récent de chaque transporteur (`cleTransporteur`), son PDF lu à la demande par `lirePdfLigne` quand la tuile arrive
  à l'écran, le type vérifié par `typeBordereau` (la règle de l'impression), puis `poserBordereau` (la fonction de
  l'impression) : le N° et la mention sont dessinés là où ils s'imprimeront. Sans bordereau de ce transporteur (ou
  illisible) : l'exemple aux données inventées, marqué **« Exemple »**. Leboncoin, Vestiaire, retour et international
  n'ont pas de transporteur rangé reconnaissable : exemple (dit).
- **Le visuel** : tuiles plus grandes, 2 colonnes à 390, 4 à 1512 ; logo + nom (jamais tronqué), l'aperçu, UNE ligne
  (« Placement automatique » / « Placé à la main · Modifier ») ; A4 · 4 par page · Thermique en un seul contrôle en
  tête ; la phrase « Créé par vrm.center s'imprime toujours, juste au-dessus du QR code ». Toucher une tuile ⇒ la
  grande feuille (le N° se glisse, la mention verrouillée).
- **Banc `scripts/bancs/tampons-page.cjs`** : R (règle pure, réglage rangé « sans mention »), S (sources : aucun
  contrôle, verrou, `veutMention = true`, l'aperçu passe par `poserBordereau`), A (l'app construite, 390 tactile et
  1512, clair et sombre : mention sur chaque tuile malgré le réglage rangé, aucun contrôle, verrou au glisser,

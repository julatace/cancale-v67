## 2. Le crochet commun `scripts/bancs/_porte-banc.cjs`

Chargé par `_meta.cjs` et en tête de chaque banc navigateur. Il ne touche **pas** à
l'app ; il répond, DANS LA PAGE, ce que répondrait un serveur sain :
- `mode=confidentialite` → `{ok:true, uid}` de la session rangée, seulement si le
  banc ne tranche pas lui-même (`confidentialite.cjs` garde ses refus : 26/0) ;
- `vrm_acces_direct` sans session → une session de banc (`BANC_SESSION_UID` pour un
  banc qui déclare son vendeur ; `vrm_banc_sans_session` pour juger l'état sans
  session — `securite.cjs`) ; `/auth/v1/*` répondu pour elle ;
- une lecture filtrée `owner=eq.<uid>` : `select=owner,…` demandé au banc sans
  `owner`, puis l'owner posé sur chaque ligne (null compris) ;
- `BANC_TRACE=1` imprime les réponses en erreur ; `BANC_PORTE_STRICTE=1` le retire ;
  un `executablePath` absent retombe sur le Chromium installé.

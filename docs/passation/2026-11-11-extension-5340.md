## Les règles

- **Mode vacances au journal** (`background.js`) : `journalVacances` après `mettreVacancesVinted` dans
  `executerCommande` ; `sorteVacances` ne rend une sorte que pour `accepte` + étape `fait` (relu chez
  Vinted) ; la sorte vient de l'état RELU (`r.vacances`), jamais de la demande. « déjà », « écart »,
  « incertain », « échec » ⇒ rien. `JOURNAL_SORTES` + `vacances_on`/`vacances_off` ; l'entrée = `t`, `s`
  seulement. Serveur (`api/_lib/securite-compte.js`, `SORTES_EXTENSION`) : `vacances_pose` /
  `vacances_retire` ; écran (`src/securiteCompte.js`) : les deux libellés. Aucune puce de filtre ajoutée
  (comme « Prix baissé » avant elle, hors `TYPES_JOURNAL`).
- **Prix de vente Vestiaire** : mesuré le 11 nov. (lecture seule) — `vc_ventes.forme` porte
  `sellerPrice:string` à côté de `sellerEarning:string` et `productPrice:string` ; la clé d'une vente = son
  n° (8 chiffres, = `productId`). `vc-inject.js` (`scalairesVente`) lit `sellerPrice` SEULEMENT écrit en
  euros au centime (`eurosEcrits`, la même lecture que `sellerEarning`) ⇒ `prixVente {valeur, devise:'EUR',
  cle:'sellerPrice'}` ; autre forme ⇒ rien. `rangerVcVentes` le rebâtit (`prixVenteVc`), le garde à la
  lecture suivante. ⚠️ La forme exacte de la chaîne n'est pas encore vue en base : si Vestiaire l'écrit
  autrement que « 250,00 € », rien n'est rangé et la facture reste refusée (jamais deviné).
  Règle (`src/facturePro/sources.js`, `venteVc`, la même dans l'app et le serveur) : prix de vente lu,
  n° (clé relue par le serveur, posée en `id`), pas annulée (`vcVenteAnnulee`), date lue ⇒ facture ;
  sinon la raison (sans prix : la phrase d'avant, mot pour mot). Désignation = titre lu, acheteur recopié.
- **Avis datés** (`capterAvis`) : `historiqueAvis` lit l'historique d'avant (projection
  `data->payload->historique` ; lecture ratée ⇒ RIEN écrit), ajoute `pointAvis` { at, total, n, c[5] },
  un point par jour, 90 jours, 120 points ; des nombres seulement. App : `evolutionHistorique`
  (`src/notesRecues.js`) — premier point des 90 jours contre le dernier, deux jours distincts au moins,
  « +N » seulement si Vinted a dit les deux totaux ; `Stats.jsx` projette `hist:data->payload->historique`.
- **Audits** (`scripts/_source-app.cjs`) : un import suivi d'un commentaire est dédoublonné, et l'import d'un
  écran voisin (`./MessagesLeboncoin.jsx`) n'est pas recollé — `audit-lbc-plus-vue-pause` était rouge
  (DEMANDE_APPAREIL puis FilLeboncoin déclarés deux fois dans le texte recollé d'App.jsx ; rien dans l'extension).
- Versions : `CODE_VERSION`, manifeste, `lbc-inject.js`/`lbc-relay.js`, `EXT_ATTENDUE` 5.340.0,
  `EXT_CAPACITES` `journalvacances`/`vcprixvente`/`avishisto`, `audit-coherence`, §8 ; zips par
  `scripts/zip-extension.cjs`.

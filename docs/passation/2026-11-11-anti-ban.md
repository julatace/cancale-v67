## 5. Pour la 5.341 (à écrire par la session qui publie l'extension)

1. **P1** — `repondreOffre` : remplacer les trois `vintedSend(acc, 'PUT'|'POST', …)` par
   `vintedPage(acc, …, { timeoutMs: 12000 })` ; `sansPage` ⇒ ne PAS marquer l'offre faite
   (`st[o.oid]` seulement si la requête est partie), la garder prévue (`pv[o.oid]`), `noterDiag
   ('offre_auto_sans_onglet')`. Même chose dans `executerPourApp` pour les chemins d'offre et de
   réponse (liste blanche `EXEC_PERMIS` inchangée). Contrôles : `audit-moteur-offres` (les PUT
   passent par la page, aucun `Authorization`), `audit-exec`.
2. **P2** — `vrm_stop_tout` : lu avec `vinted_offres_auto` dans `offreAutoReglages` (illisible ⇒
   arrêté), dans `miseEnLigneTick` et au début de chaque tâche de la file de Republier (comme le
   frein, 5.313 R1). L'app : « Tout arrêter » pose `{ jusqua: maintenant + 24 h }`, « Reprendre »
   l'efface. Capacité `stoptout`.
3. **P3** — dans `repondreOffre`, un refus `r.ok === false` avec un statut 4xx autre que 429/403 ⇒
   `poserFreinRepub(uid, r)` (le texte « restrict/suspend » ⇒ 24 h).
4. **P4** — `offreAutoReglages` : `Number(String(x).replace(',', '.'))`. `audit-offres-sures` porte
   déjà le cas « 45,5 » (aujourd'hui : l'aperçu dit « seuil illisible », comme le moteur).

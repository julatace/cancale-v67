Relier ta boîte e-mail (Gmail, iCloud, Yahoo)

Les e-mails de Vinted, Leboncoin, Mondial Relay ou Chronopost portent les codes de retrait, les bordereaux et les dates limites. Ta messagerie en fait suivre une copie vers ton adresse VRM. Ton courrier personnel, lui, ne part pas.

Ton adresse VRM et la règle à copier sont dans VRM : Réglages → Mes e-mails. VRM t’envoie aussi un lien à ta boîte : clique-le depuis VRM connecté, il prouve que l’adresse est à toi.

Gmail

  1. Sur ordinateur, dans Gmail : la roue en haut à droite → Voir tous les paramètres.
  2. Onglet Transfert et POP/IMAP → Ajouter une adresse de transfert → colle l’adresse de VRM.
  3. Gmail envoie un code de validation à VRM : il apparaît dans Réglages → E-mails → Adresses une fois ton adresse confirmée. Tape-le dans Gmail.
  4. Dans la barre de recherche : l’icône des options → champ De : colle la règle donnée par VRM → Créer un filtre → coche Transférer à l’adresse de VRM.

iCloud Mail

  1. Sur icloud.com/mail (ordinateur) : la roue → Réglages → Règles.
  2. Ajouter une règle → Si un message est de → l’expéditeur (un par règle).
  3. Alors → Transférer à → colle l’adresse de VRM. Recommence pour chaque expéditeur de la liste.

Le relais d’Apple (« Masquer mon adresse »)

Si ton compte Vinted a été créé avec « Se connecter avec Apple », ses e-mails passent par une adresse relais d’Apple. Ce n’est pas une boîte : Apple fait suivre vers UNE de tes boîtes. Il suffit que ce soit une boîte déjà reliée à VRM.

  1. Sur l’iPhone : Réglages → ton nom → iCloud → Masquer mon adresse e-mail.
  2. Transférer à → choisis une boîte qui arrive déjà à VRM.
  3. Réglages → ton nom → Connexion et sécurité → Se connecter avec Apple → Vinted : le transfert des e-mails doit être activé.

Yahoo

Yahoo ne fait suivre les e-mails qu’avec Yahoo Mail Plus (payant), et il envoie alors toute la boîte. Le plus simple, gratuit : dans les paramètres de ton compte Vinted, remplace l’adresse par celle d’une boîte déjà reliée à VRM (Gmail ou iCloud).

Rien ne se perd. Aucun e-mail n’est jeté : celui qu’aucune règle ne reconnaît est gardé tel quel. C’est l’adresse de réception qui décide à quel compte VRM il appartient, jamais l’expéditeur.

Outlook. Certains comptes Outlook refusent le transfert automatique. Si, après le prochain e-mail de Vinted, rien n’arrive dans VRM, c’est qu’Outlook l’a bloqué.

# Sources des logos

Ces quatre fichiers sont FABRIQUÉS depuis `src/plateformes/marques.js` (la seule source des
tracés) par `node scripts/marques-svg.cjs --ecrire` ; ne pas les retoucher à la main.

- Vinted et eBay : Simple Icons 16.37.0, https://github.com/simple-icons/simple-icons, CC0-1.0.
- Leboncoin : marque dessinée pour VRM (15 nov. 2026 : le carré au coin replié) — Simple Icons
  n'en a pas. Ce n'est PAS le logo officiel de Leboncoin.
- Vestiaire : monogramme « VC » dessiné pour VRM (15 nov. 2026, un V et un C au même trait) —
  Simple Icons n'en a pas. Ce n'est PAS le logo officiel de Vestiaire Collective.

Les marques appartiennent à leurs propriétaires ; elles ne servent qu'à reconnaître le site
dans VRM. Les SVG sont servis localement (aucune requête extérieure).
